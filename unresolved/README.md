# 未解决问题与来源冲突

未解决问题是研究成果的一部分，不应被隐藏或强行消除。

每项问题应记录编号、具体命题、已有证据、冲突来源、已尝试查证路径、下一步建议、对小说的影响和最后核查日期。

优先级：
- P0：影响核心历史判断或小说主线；
- P1：影响重要人物、军事部署或关键事件；
- P2：补充性细节。

无法解决时应保留未决状态。
