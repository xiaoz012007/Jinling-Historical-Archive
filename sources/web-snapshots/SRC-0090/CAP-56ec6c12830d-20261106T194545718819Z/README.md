原HTML是本轮获得的响应实体字节；WARC只含末次HTTP响应，响应头经白名单重构，未保存Cookie等凭据。它不含CSS、图片、外部脚本和重定向响应体，不是完整网页或网站归档。网页发布/更新时间无法确定时保留空值，历史文书日期另见来源表。
