# 小说史实使用规则

来源性质P/S/T/unknown只描述资料类型。使用某条史实前，必须同时检查具体命题的支持状态、原文取得及阅读范围、定位、时间精度和限制。官方目录也不能替代原件内容；扫描已下载不等于已经读过。

| 情形 | 正文可用方式 | 禁止用法 |
|---|---|---|
| 原件与命题对应、支持充分 | 按所证范围叙述，保存来源与定位 | 扩展为原件没有说的动机或对白 |
| 回忆或单一来源 | 用“据某人后来回忆”等限定；情节可降低精度 | 将回忆时间当同期收发时间 |
| 来源冲突 | 并列版本或采用不依赖争议细节的场景 | 静默挑一个最合剧情的版本 |
| 只有目录 | 写目录确有某题名、日期或馆藏条目 | 编造全文、签名、发送或接收过程 |
| 日期或阶段可核、分钟不可核 | 只到日、上午/下午或有据区间 | 为同步人物行动自行补分钟 |
| 数字口径不一 | 分列日期、单位、口径及作者 | 将编制、战斗兵、伤员等混加为实有人数 |
| 模型输出 | 明示I/F条件推演和参数 | 当作历史实际运输或最终获救人数 |
| 小说场景与对白 | 明确属于F，另记事件和连锁变化 | 加引号并伪称真实人物原话 |

任职、受命、开始视事、正式发表及战斗序列电文分别处理。命令形成、签发、发送、接收、送达、阅读和执行分别处理。某部成功突围或覆灭，均不能反推该部是否接令。

草鞋峡、鱼雷营、中山码头等事件的司法认定、证人陈述、日记记录和后世研究分列。不得以共同犯罪责任分配各部队实际杀害人数，不得把拘押人数自动变成杀害人数，也不跨案机械求和。某个精确数字或日期待核，不构成否定已有充分证据支持的暴行的理由。

任何新增人物内心、未见原文的命令或对白，均须标F。作者说明应披露唐生智提前改善组织、调整部署、反事实运输安排及最终战死等核心偏离；涉及真实人物具体行为的新增F也应可追溯到台账。

章节将来引用史实，至少记录event_id、source_id及定位、使用的精度、是否采用限定措辞；引用F记录fiction_event_id。真实史料库不得因小说剧情反向改写。原件纠错只凭证据，保留旧值、修订理由和版本。

本轮没有授权或执行小说正文创作，也未改写既有章节。
