# B轨：条件运输模型

模型EV-B-003-01对应小说筹备、分流、配额、联络和接续的F决策，计算参数为I测试值，未设救人数目标。历史未知项不回填。模型及操作说明见[README](README.md)，公式、守恒与局限见[FORMULAS](FORMULAS.md)。

三案固定25项共同参数，仅变化6项组织参数。模型从11月27日的假设工作日开始，不因F筹备窗口可从11月20日起就多算满负荷运输天数。汽车闭合往返、船位、军民共用槽位、城门入口和北岸接续分别受限；四条路线分配同一个需求池，串联不重复计人。

“链条完成”到的是各路线预设的不同终点，不等于统一安全后方，更不等于最终生存。岸边待转运与步行待完成的人没有从守恒式消失；默认不跨日清理这两类等待库存，是已声明的模型简化。历史实际运输和获救字段继续为空。

工作簿比较表为计算快照。改参数需刷新，改公式必须重新核验；不能只看参数一致提示就宣布所有编辑已验。Python复算为标准库程序；Excel生成与当前计算检查使用artifact-tool，尚未完成Microsoft Excel原生环境验证。
