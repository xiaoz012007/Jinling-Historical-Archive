# 证据模型与标记规范

本项目将资料性质与具体命题的证据状态分开管理。

## 一、来源性质字段

当前来源表的`source_nature`及关联表的`source_nature_from_register`只允许以下四值：

| 标签 | 含义 | 示例 |
|---|---|---|
| P | 原始史料或同期记录 | 同期电报、作战命令、日记、书信、档案、同期照片 |
| S | 学术研究成果 | 学术专著、期刊论文、学位论文 |
| T | 一般二手资料 | 新闻报道、通俗读物、网络文章 |
| unknown | 来源性质尚未完成判定 | 只有待核书目或不足以判断载体性质的材料 |

P/S/T描述来源类型，不代表命题自动真实。`unknown`仅表示来源类型尚未定性，不能代替`unverified`、`conflicted`等命题状态；无法取得原文也不必然使已知的来源类型变成`unknown`。

PR #1收口将69项来源的旧`U`改为`unknown`，保留原值于`source_nature_original`和[迁移表](../sources/SOURCE_NATURE_MIGRATION.csv)。关联表同步保留`source_nature_from_register_original`。这次迁移不重新判断史实、不升级来源、不改变命题状态。

研究内容仍可独立标记：I为研究推断或模型；U为未决研究问题；F为小说虚构。这三个标记不进入上述当前来源性质字段，原值存档也不作全局替换。I不能冒充已证史实；F不得进入历史事实层。

## 二、命题证据状态

- supported：现有证据对该命题提供明确支持；
- supported_with_limits：有支持，但仅限于明确的时间、范围或语义；
- single_source：目前只有一个来源支持；
- conflicted：来源之间存在尚未解决的冲突；
- unverified：尚未获得足够证据；
- contradicted：被更可靠且直接相关的证据否定；
- not_applicable：不适用于历史断言，例如纯虚构设定。

状态变化必须附修订记录。找到一个网页不等于命题已经核实。

## 三、独立互证

两个网页若转载同一份档案、同一篇论文或同一段回忆录，属于同一来源族，不是两个独立来源。翻译版、节录版、转录版也应记录其母本关系。

## 四、引用边界

引用应能定位到页码、档号、段落、条目或稳定网页锚点。对扫描件注明扫描版本及PDF页码；如印刷页码不同，两者分别记录。

摘录必须忠实原文并遵守版权限制。无法直接取得原文时，明确写明“据某研究转引”，不可伪装为亲自核对原档。

## 五、小说标记

小说正文中的虚构命令、对话、人物心理、时间和结果，应在创作台账中标为F，并关联真实历史背景及偏离点。
