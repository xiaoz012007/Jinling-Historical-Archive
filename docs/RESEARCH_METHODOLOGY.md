# 研究方法与质量控制

## 1. 研究目标

本项目整理1937年南京保卫战相关史料，建立可追溯的事件、人物、军事组织、交通疏散和国际救援资料体系，并记录证据冲突与未决问题。研究数据库独立于架空历史小说《金陵不退》。

## 2. 从来源到结论

每项重要历史结论应建立链条：来源记录 → 原文定位 → 准确摘录或摘要 → 支持的命题 → 限制与反证 → 当前证据状态 → 修订记录。

一份文献可以支持某个命题的一部分，却不能自动支持同一段落中的所有细节。

## 3. 来源核查

优先寻找原始档案、同期电报、命令、日记、书信、外交文件、司法材料和同期照片。学术研究用于解释、交叉核对和提供档案线索。媒体与网络文章主要用于发现线索。

记录文献是否为原件、抄件、译件、转录或后期整理；作者是否亲历；形成时间与事件时间的距离；文献是否完整；是否存在删节、编辑注或翻译差异；不同来源是否依赖同一原始材料。

## 4. 时间记录

必须区分事件发生、命令形成、签发、发报、收报、送达、阅读、执行及后来记录时间。若只能确认日期，不得补出小时和分钟。不同来源的时间说法应并列记录。

## 5. 数字与计算

兵力、伤亡、人口、运输能力和撤离人数必须保留统计口径。不得将编制数、实有数、战斗兵、非战斗人员、伤员和失踪人员混为一谈。

模型输出必须记录输入参数及来源、公式、单位、时间窗口、约束条件、敏感性、不确定性和测试方法。条件模型不得表述为历史实际数量。

## 6. 冲突与未知

证据冲突时分别记录各版本及其来源，不得静默选取符合预期的版本。未找到资料不等于事件没有发生。无法解决的问题应保留在未决清单。

## 7. 修订与可复现

每次修订记录日期、修改人、原值、新值、理由、来源和影响文件。重要表格尽可能使用可复算格式，并保留计算说明。原始来源文件不得被整理版覆盖。
