# 历史事实与小说架空边界

## 1. 两套记录分离

历史数据库只记录有来源支持的历史材料、研究结论、争议和未知。小说数据库记录人物塑造、虚构场景、架空命令、虚构对话和反事实后果。小说正文中的虚构内容不得回写为历史事实。

## 2. 《金陵不退》的核心架空前提

当前小说设定包括：
- 唐生智提前改善南京军民撤离组织；
- 提前改善守城组织和撤退预案；
- 对部分部队部署及协同作出架空调整；
- 唐生智最终留在南京并战死。

以上均为F类小说设定，不是历史事实。

## 3. 写作使用规则

- 真实人物的真实职务、公开言论和已记录行动应有来源。
- 未有史料支持的私人对话、内心活动和具体场景，必须作为小说创作处理。
- 不得伪造历史电报、军令、档案、日记或照片说明。
- 若正文需要虚构命令，应采用明显属于小说创作的方式，并在架空事件台账登记。
- 未决的历史时间可用日期、时段或不确定叙述，不得擅自补成精确时刻。
- 条件模型结果不得写成历史实际撤离人数或实际获救人数。

## 4. 反事实因果链

每个重大架空事件都应记录：真实历史基线 → 小说改变 → 当时可用资源 → 直接后果 → 次生影响 → 仍然不确定的结果。
