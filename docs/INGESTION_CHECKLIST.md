# 史料入库检查清单

本清单用于将Task002及后续研究成果逐项纳入公开仓库。完成“文件入库”不等于其中所有历史断言已经核实。

## A. 输入与原件保护
- [ ] 确认文件来自哪个交付包、版本和路径
- [ ] 记录原始文件名、大小、SHA-256
- [ ] 保留原始文件，不覆盖、不静默修改
- [ ] 区分原件、工作副本、OCR文本、转录和阅读版
- [ ] 检查压缩包完整性及内部文件清单

## B. 来源身份
- [ ] 分配稳定source_id
- [ ] 记录标题、作者/机构、形成日期、出版信息
- [ ] 记录档号、卷宗、页码或网页定位
- [ ] 记录原始URL和最终URL
- [ ] 记录实际访问日期和访问状态
- [ ] 识别原件、抄件、译件、转录、节录或后期整理本
- [ ] 识别同源转载、翻译和版本关系

## C. 具体命题核查
- [ ] 明确来源支持的具体命题
- [ ] 确认是否实际阅读原文
- [ ] 记录摘录或准确摘要及页码
- [ ] 记录该来源不能证明什么
- [ ] 检查反证及来源冲突
- [ ] 设置命题证据状态
- [ ] 不将单一来源或同源转载误作独立互证

## D. 网页快照
- [ ] 保存原始URL、最终URL、访问时间、标题及发布机构
- [ ] 尝试保存WARC或原始HTML（在许可和技术允许时）
- [ ] 制作PDF阅读副本（在许可允许时）
- [ ] 必要时保存截图
- [ ] 记录动态内容、缺图、脚本渲染及页面不完整情况
- [ ] 计算SHA-256
- [ ] 检查快照与当前网页是否一致
- [ ] 按网页快照规范评估公开再分发权
- [ ] 不能公开全文时改为metadata_only或link_only

## E. 版权与隐私
- [ ] 核查版权声明和许可
- [ ] 核查网站使用条款及再分发限制
- [ ] 核查档案馆/图书馆的下载与公开条件
- [ ] 检查个人信息和敏感数据
- [ ] 记录rights_status
- [ ] 版权不明时不公开上传全文

## F. 发布前检查
- [ ] 文件名、路径和编码规范
- [ ] CSV/JSON格式有效
- [ ] 链接可访问或已记录失效状态
- [ ] 哈希与文件对应
- [ ] 更新来源索引
- [ ] 更新修订日志
- [ ] 更新README或专题说明
- [ ] 第二人复核重要结论
- [ ] 公开内容不包含内部备注、凭据或未经许可材料

## 状态

建议使用：not_started、in_progress、needs_review、approved_for_publication、metadata_only、blocked_rights、rejected。

只有完成必要检查后，才能标记为approved_for_publication。
