# 项目缘起：为什么想留下《金陵不退》

这个项目最初源于对南京保卫战、唐生智及其历史评价的思考。想写一部历史架空小说，也想借此认真看看当时的军事组织、撤离和决策问题。

项目发起者的原话是：

> 其实以上都是astra写的，我也说不来这些，但是我还是希望能留下点东西。

还有一句更直白的感想：

> 唐生智真的是buff叠满，然后拉了一坨大的。

这些话保留在这里，作为个人表达和项目起点，不是历史证据，也不替代对唐生智具体行为和责任的研究。

在AI协助下，小说考据逐渐积累成了资料库。后来决定把能够合法公开的整理成果留下来，让其他人可以查阅、纠错和继续补充。即使小说最终没有完成，资料库也应当能够独立存在。

项目发起者不自称专业历史研究者，但希望尽可能严谨地留下可复核的资料。个人感想可以直说，研究结论仍须回到证据；不知道的地方就留白。
